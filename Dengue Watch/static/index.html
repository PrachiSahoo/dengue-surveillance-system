🏆 Foundation Models vs Supervised LSTM Benchmark

Comparative evaluation across 1, 2, 4, and 8-week horizons using MASE, WQL, and PPE

Short-Term (1–2 Wks)

Chronos-Bolt achieves 0.643 MASE vs LSTM's 0.910 MASE at h=1 (-29.3% error gap). Zero-shot provides immediate deployment without local training.

Mid-Term (4 Wks)

Performance parity is observed. Chronos-Bolt (1.124 MASE) and Stacked-LSTM (1.344 MASE) perform competitively as seasonal cycles begin to balance.

Long-Term (8 Wks)

Chronos-Bolt strongly outperforms (-31.1% MASE reduction). LSTM autoregression compounds error, while foundation model pretraining preserves macro trends.
